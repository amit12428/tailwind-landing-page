# Tailwind Landing Page

A modern and responsive landing page built with HTML, CSS, JavaScript, Tailwind CSS, and GSAP animations.

## 🚀 Live Demo

[View Live Website](https://amit12428.github.io/tailwind-landing-page/)

## ✨ Features

- 📱 Fully responsive design
- 🎨 Modern and clean UI
- ⚡ Tailwind CSS styling
- 🎬 Smooth animations using GSAP
- 🖥️ Desktop and mobile friendly
- 🖼️ Custom images and assets
- 📱 Optimized for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Custom styling
- **JavaScript** – Interactivity and functionality
- **Tailwind CSS** – Utility-first CSS framework
- **GSAP** – Animations and motion effects
- **Git & GitHub** – Version control and deployment

## 📁 Project Structure

```text
tailwind-landing-page/
│
├── assets/             # Images and SVG assets
│
├── index.html          # Main HTML file
├── style.css           # Custom CSS
├── output.css          # Generated Tailwind CSS
├── script.js           # JavaScript and GSAP animations
│
├── package.json        # Project dependencies and scripts
├── package-lock.json   # Dependency lock file
└── .gitignore          # Git ignored files
```

## 📱 Responsive Design

The landing page is fully responsive and optimized for:

- Desktop
- Tablet
- Mobile

## 🎬 Animations

GSAP is used to create smooth and engaging animations throughout the landing page.
